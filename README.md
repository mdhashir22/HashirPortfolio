## About the Project

This portfolio was designed and developed from scratch as my personal developer website.

The goal was to create more than a simple portfolio — I wanted an interface that reflects my interest in development while maintaining a clean, responsive, and professional user experience.

The website features a custom **dark cyber-inspired theme with neon green accents**, interactive animations, and a fully responsive layout across desktop, tablet, and mobile devices.

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/mdhashir22/HashirPortfolio.git
```

### 2. Open the project

Open the solution/project in **Visual Studio**.

### 3. Restore dependencies

Visual Studio should automatically restore the required .NET dependencies.

Alternatively:

```bash
dotnet restore
```

### 4. Run the application

```bash
dotnet run
```

Or simply press the **Run / HTTPS** button inside Visual Studio.

> This project targets **.NET 10.0**.
